# Mystery Island — The Lost Lighthouse

An interactive Python text-adventure game where players explore a
mysterious island, collect objects, solve puzzles and restore a
lighthouse to escape.

## Project Status

Under development.

## Technologies

- Python 3.12
- Python standard library
- unittest

## Project Structure

- `main.py` — Game entry point.
- `game.py` — Game logic.
- `tests/` — Automated tests.
